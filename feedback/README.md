from a checkout of this branch. The script prints the new comments, reviews and head changes since the
last checkpoint on the porter's open pull requests and on the PR numbers in `watch`. Once they are
dealt with, it runs again with `--save` and the new `checkpoint.json` is committed here. Claude's own
posts end with the "Generated by [Claude Code]" footer and are not counted as feedback.
