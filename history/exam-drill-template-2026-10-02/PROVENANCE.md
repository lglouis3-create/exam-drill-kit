# Provenance of this folder

This is the `exam-drill-template/` folder as it stood in Medicinal-chemistry's local
history at commit `baed236` (2026-10-02, "Template: port the PHAR 4344 engine upgrades
…"). That history was never pushed to GitHub; Louis supplied it on 2026-11-01 as
`medchem-repo.bundle` (md5 `0f18c31d3284b4050dfdd590af9111be`) and as
`exam-drill-template.zip` (md5 `98dadd13fbe0383fa59d1ea5a519a48f`). The 29 files of the
zip match `exam-drill-template/` at `baed236` byte for byte.

The full history, including the 09/21 round of the PHAR 4342 drill (92 questions,
`course.js`, `ingest.py`), is preserved on GitHub as branch `restore/2026-09-21-round`
in `lglouis3-create/Medicinal-chemistry`.

The files are kept unchanged here as the candidate starting point for the kit core
(`review/proposed-core.md` §0, `review/findings.md` §11). `PROVENANCE.md` is the only
file added.

The `CLAUDE.md` in this folder is part of the archived template. Its rules are for a
course's drill source tree once the template is copied into one; they do not apply to
work on the kit itself.
